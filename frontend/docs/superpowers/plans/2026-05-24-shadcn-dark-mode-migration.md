# shadcn/ui Migration with Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Material UI with shadcn/ui, configure Tailwind CSS, and set the warm dark-mode palette from DESIGN.md as the standard default theme.

**Architecture:** Install Tailwind CSS v3 + PostCSS, run `npx shadcn@latest init` to scaffold components and CSS variables, override the generated CSS variable values with the warm dark-palette from DESIGN.md (`#141413` background, `#c96442` terracotta primary), pin dark mode permanently via `class="dark"` on `<html>`, then replace every MUI import across 4 files (main.tsx, App.tsx, NavBar.tsx, theme.ts) with Tailwind classes and shadcn components.

**Tech Stack:** Tailwind CSS v3, shadcn/ui (latest), React Router DOM 7, React 19, Vite 8, TypeScript

## Task 7: Rebuild NavBar with shadcn Button + Tailwind

**Files:**
- Rewrite: `src/components/NavBar/NavBar.tsx`

The NavBar must:
- Use a sticky `<header>` with warm dark border (`border-border`)
- Keep React Router `NavLink` for active-state detection
- Use shadcn `Button` for the Cart CTA (terracotta/primary variant)
- Apply Tailwind classes for layout, spacing, and typography

- [ ] **Step 1: Rewrite `src/components/NavBar/NavBar.tsx`**

```tsx
import { NavLink } from 'react-router-dom'
import { Button } from '@/components/ui/button'
import logo from '../../assets/logo.svg'
import { cn } from '@/lib/utils'

const navLinks = [
  { to: '/', label: 'Home', end: true },
  { to: '/products', label: 'Products' },
  { to: '/categories', label: 'Categories' },
  { to: '/promotions', label: 'Promotions' },
]

export function NavBar() {
  return (
    <header className="sticky top-0 z-50 w-full border-b border-border bg-background/95 backdrop-blur-sm">
      <div className="mx-auto flex h-14 max-w-7xl items-center gap-6 px-4 sm:px-6 lg:px-8">
        <NavLink to="/" className="mr-4 flex items-center shrink-0">
          <img src={logo} alt="Logo" className="h-7 w-auto" />
        </NavLink>

        <nav className="flex flex-1 items-center gap-1" aria-label="Main navigation">
          {navLinks.map(({ to, label, end }) => (
            <NavLink
              key={to}
              to={to}
              end={end}
              className={({ isActive }) =>
                cn(
                  'rounded-md px-3 py-1.5 text-sm font-sans transition-colors',
                  isActive
                    ? 'text-foreground font-medium'
                    : 'text-muted-foreground hover:text-foreground',
                )
              }
            >
              {label}
            </NavLink>
          ))}
        </nav>

        <Button asChild className="ml-auto shrink-0">
          <NavLink to="/cart">Cart</NavLink>
        </Button>
      </div>
    </header>
  )
}
```
